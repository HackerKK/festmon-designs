# FestMon — выбор дизайна панели оператора

Интерактивные макеты панели оператора FestMon (только интерфейс, данные фейковые) и голосование за лучший вариант.

Смотреть: https://hackerkk.github.io/festmon-designs/

- `index.html` — презентация: переключение между вариантами A–G и форма голосования в конце
- `compare.html` — все варианты на одной странице с плюсами и минусами
- `a_…` – `g_…` — сами макеты, `assets/` — общие фейковые данные и стили
